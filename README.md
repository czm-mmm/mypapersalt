# SEA SALT & PAPER · 非官方单机网页版

面向中文玩家的《Sea Salt & Paper》基础规则单机网页改编。卡面采用重新绘制的几何折纸图形，不包含原版扫描图、照片或 Logo。

## 当前能力

- 2–4人局，1名真人与1–3名基础AI。
- 抽二留一、双弃牌堆、四种Duo、STOP、最后机会和多轮计分。
- 同类Duo较多时可指定具体打出的卡牌；最后机会会按规则公开并保护已完成最终回合的手牌。
- 58张基础牌、11种颜色总量及主要计分规则。
- 响应式手机/桌面牌桌，卡牌不重叠，颜色和牌型保持清晰。
- 复用此前选定的轻量选牌与出牌音效。

## 运行

```bash
npm install
npm run dev
npm run verify
```

## 数据核对说明

牌型数量、颜色总量、回合流程和结算规则依据 Bombyx 官方英文基础版规则书与游戏帮助资料。逐张“牌型—颜色”关联集中在 `src/core/cards.ts`，在取得实体牌逐张清单后应进行最终复核；这种设计保证复核只影响数据，不影响规则和界面。
